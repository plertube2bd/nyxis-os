# 라이선스 정책 (외부 코드 가져오기 규칙)

이 저장소의 라이선스는 **GPL-3.0** (`LICENSE`) 이다. 외부 오픈소스 코드를 가져올 때는 아래 규칙을 따른다.

## 가져와도 되는 것
| 원본 라이선스 | 가능 여부 | 조건 |
|---|---|---|
| MIT / BSD-2 / BSD-3 / ISC / Zlib / Apache-2.0 | 가능 | 원본 저작권 표시와 라이선스 문구 유지, `THIRD_PARTY.md` 에 기록 (Apache-2.0 은 GPL-3.0 과 호환) |
| GPL-3.0 / GPL-2.0-or-later / LGPL | 가능 | 원본 저작권/라이선스 표시 유지, 파일 헤더에 출처 기록 |
| **GPL-2.0-only (Linux 커널 대부분)** | **복사 금지** | GPL-3.0 과 호환되지 않는다. Linux 코드는 "구조/아이디어 참고"만 하고 직접 다시 작성한다 |
| 라이선스 불명 / 비공개 | 금지 | |

BSD 계열(FreeBSD, OpenBSD, NetBSD)은 대부분 BSD-2/3 이므로 코드를 가져오기에 가장 안전하다.

## 절차
1. 가져온 파일 맨 위에 출처(프로젝트, 파일 경로, 커밋/버전, 원저작자, SPDX 식별자)를 주석으로 남긴다.
2. `THIRD_PARTY.md` 에 항목을 추가한다 (아직 가져온 코드가 없으므로 파일은 필요할 때 만든다).
3. 가져온 코드도 이 프로젝트의 규칙(C89, `-Werror -Wextra`, 주석)에 맞게 고친다. 고친 내용은 원본 표기 옆에 적는다.

## 현재 상태
- 2026-09 감사에서 작성/수정한 코드는 모두 새로 작성했고 외부 소스를 복사하지 않았다.
- 빌드 의존성 `gnu-efi`(BSD 계열)는 소스에 포함하지 않고 시스템 패키지로 링크만 한다.
